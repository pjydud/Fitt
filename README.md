# 매일 운동기록 PWA

모바일에서 러닝, 웨이트, 몸무게를 빠르게 기록하는 홈화면 추가용 PWA입니다.

## 기능
- 날짜별 운동 기록
- 기록이 있는 날짜만 캘린더 점 표시
- 몸무게 기록
- 러닝 거리/시간/메모 기록
- 웨이트 운동명/무게/횟수/세트 기록
- 이번 주 러닝 거리, 운동 횟수, 연속 기록, 최근 몸무게 요약
- 최근 기록 확인
- JSON 백업
- GitHub → Vercel 배포 가능
- 홈화면 추가 가능

## 모바일에서 배포 방법
1. GitHub 앱 또는 웹에서 새 저장소를 만듭니다.
2. 압축을 풀고 안의 파일들을 저장소에 업로드합니다.
3. Vercel에서 해당 GitHub 저장소를 Import 합니다.
4. Framework Preset은 `Other` 또는 기본값으로 둡니다.
5. Deploy를 누릅니다.
6. 배포 주소를 크롬으로 열고 메뉴에서 `홈 화면에 추가`를 누릅니다.

## 주의
기록은 브라우저의 localStorage에 저장됩니다. 휴대폰을 바꾸거나 브라우저 데이터를 삭제하면 기록이 사라질 수 있으니, 가끔 `백업` 버튼으로 저장하세요.
